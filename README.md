# Smart City Traffic & Road Network Analyzer

A graph-based traffic management and route optimization system built using C++ and Data Structures & Algorithms.

## Features

- Shortest Path Routing using Dijkstra's Algorithm
- Critical Road Detection using Tarjan's Algorithm
- Connectivity Analysis using DFS
- Traffic-aware Route Optimization
- Smart City Road Network Modeling
- Emergency Route Planning

## Tech Stack

- C++
- STL
- Graph Algorithms
- Data Structures

## Algorithms Used

- Dijkstra's Algorithm
- Tarjan's Bridge Detection
- DFS
- BFS
- Priority Queue
- Adjacency List

## Project Overview

The project models a city's road network as a graph where:
- Nodes represent locations/intersections
- Edges represent roads
- Traffic conditions influence route selection

The system identifies optimal routes and critical roads that can affect overall network connectivity.
